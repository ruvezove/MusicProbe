# MusicProbe

Windows-утилита для поиска точных копий аудиофайлов и группировки разных версий треков. Интерфейс на русском, тёмная тема, обработка в фоне.

## Скачать и запустить

[Скачать MusicProbe для Windows x64](dist/MusicProbe-Windows-x64.zip?raw=true)

Распакуйте архив целиком и запустите `MusicProbe.exe`. Файл `MusicProbe.exe.config` должен оставаться рядом с программой.

Требования: Windows x64, .NET Framework 4.8 и `ffprobe.exe` в системном PATH. Rust и Node.js для запуска не нужны. Программа использует C# и WPF.

## Как работает

1. Выберите папку с музыкой. Вложенные папки не сканируются.
2. Настройте обработку и выполните анализ.
3. Проверьте таблицу: файл, действие, причина и будущий результат.
4. Нажмите «Применить» и подтвердите план.

До применения исходные файлы не изменяются.

### Точные копии — Duplicates

Файлы считаются точными копиями только при совпадении полного SHA-256. Лишние копии перемещаются в `./Duplicates` или выбранную папку. Частичные хеши служат предварительной проверкой.

### Разные версии — Resorting

Для группировки должны совпадать исполнитель и название. В названии не учитываются пунктуация, регистр и лишние пробелы. Например, «Дым сигарет, с ментолом» и «Дым сигарет с ментолом» попадают в одну группу.

После отделения точных копий все оставшиеся разные версии группы получают номера `1_`, `2_` и далее. По умолчанию они перемещаются в `./Resorting` для ручной сортировки. Можно выбрать другую папку или отключить перенос, оставив нумерацию в исходной папке. Группировка по тегам не является сравнением звучания.

Содержимое файлов сохраняется. Занятые имена не перезаписываются. Перед применением проверяется, что исходные файлы не изменились; при ошибке переноса программа пытается восстановить исходные пути и сообщает о неудавшемся восстановлении.

## Настройки

- Отдельное число потоков для `ffprobe`, частичного и полного хеширования.
- Допуск длительности, размер чтения с краёв, максимальная длина имени и тайм-аут.
- Глобальный поиск точных копий среди файлов одинакового размера.
- Автоматические или выбранные вручную папки Duplicates и Resorting.
- Сортировка таблицы и фильтр изменений и ошибок.

Пути и параметры сохраняются в `%LOCALAPPDATA%\MusicProbe\settings.json`.

## Сборка

На Windows x64 с .NET Framework 4.8:

```powershell
.\source\build.ps1
```

Скрипт использует компилятор C# из .NET Framework. Результат — `MusicProbe.exe` и `MusicProbe.exe.config` в корне проекта. Внешних NuGet-зависимостей нет.

## Проверки

```powershell
.\source\build.ps1 -Tests
```

Для тестов нужны `ffmpeg.exe` и `ffprobe.exe` в PATH. Проверки создают временные аудиофайлы и открывают тестовое окно WPF; настройки пользователя изолированы от тестов.

В опубликованной сборке пройдены 48 проверок: SHA-256, группировка по пунктуации, обе папки назначения, конфликты имён, откат, сохранность содержимого, повторный анализ, отмена, сохранение настроек и виртуализация таблицы на 50 000 строк.
